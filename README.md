# Legacy

![Icon](https://git.trueog.net/trueog/website/raw/branch/main/assets/images/logos/Logo-Alternate-Transparent.png)

*ad astra per aspera*

Archived and superseded projects tracked by TrueOG Network, plus server software retained only for
license purposes.

Each component remains an independent Gitea repository and is pinned here as a submodule:

- [Staff-OG-Legacy](https://git.trueog.net/trueog/Staff-OG-Legacy), the earlier punishment system, superseded by Staff-OG
- [SubstAgent-Old](https://git.trueog.net/trueog/SubstAgent-Old), superseded by SubstAgent
- [Multiverse-Core](https://git.trueog.net/trueog/Multiverse-Core), world management, superseded by MyWorlds
- [Bukkit](https://git.trueog.net/trueog/Bukkit), the Bukkit API at Minecraft 1.19.4, retained for license purposes only
- [Spigot-API](https://git.trueog.net/trueog/Spigot-API), the Spigot API at Minecraft 1.19.4, retained for license purposes only
- [Paper](https://git.trueog.net/trueog/Paper), retained for license purposes only
- [Pufferfish](https://git.trueog.net/trueog/Pufferfish), Pufferfish at Minecraft 1.19.4, retained for license purposes only

See each individual submodule for its license and attribution.
